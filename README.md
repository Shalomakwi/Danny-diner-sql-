# Danny's Diner SQL Case Study

## Project Overview

This project uses SQL to analyse customer purchasing behaviour at Danny's Diner, a restaurant that sells sushi, curry, and ramen.

The goal is to answer business questions about customer spending, restaurant visits, popular menu items, membership behaviour, and loyalty points.

## Tools Used

* MySQL
* MySQL Workbench
* SQL

## Database Tables

The project uses three tables:

* **sales:** Contains customer purchases, order dates, and product IDs.
* **menu:** Contains product names, IDs, and prices.
* **members:** Contains customer membership dates.

## Business Questions

The SQL queries investigate:

1. Total amount spent by each customer.
2. Number of days each customer visited the restaurant.
3. First menu item purchased by each customer.
4. Most purchased item overall.
5. Most popular item for each customer.
6. First item purchased after becoming a member.
7. Item purchased just before becoming a member.
8. Total items purchased and amount spent before membership.
9. Loyalty points earned by each customer.
10. Loyalty points earned by members by the end of January, including the first-week bonus.

The analysis examines customer spending, purchasing frequency, menu popularity, and loyalty-point calculations.
